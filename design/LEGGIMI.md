# Design di Ritmo

Una schermata per file (telefono 390 x 844). Sono file del canvas di design: servono come riferimento visivo e di contenuto, non come codice da copiare.

- Livello.dc.html: profilo atleta (difficoltà, esperienza, giorni)
- Main.dc.html: Oggi (streak, livello, allenamento del giorno)
- Allenamento.dc.html: allenamento in corso
- Progressi.dc.html: progressi e record
- SfidaLobby.dc.html: sfida, scelta modalità e amici
- SfidaLive.dc.html: sfida live di push-up (tema scuro)
- Cibo.dc.html: diario cibo e macro
- Nutrizione.dc.html: consigli alimentari

Note per leggerli: gli stili sono inline (colori, misure, raggi). Le parti tra {{ }} e i tag sc-for / sc-if sono valori dinamici; i valori e le liste si trovano nello script in fondo a ogni file. I link tra file (href="X.dc.html") indicano la navigazione tra schermate.
